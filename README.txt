SKIDRUSH STUDIO WEBSITE

Files
- index.html: complete responsive GitHub Pages website
- assets/logo.png: generated SkidRush logo used by the website

Publish to GitHub Pages
1. Download and extract skidrush-website.zip.
2. Open your repository: https://github.com/skidrush27/skidrush27.github.io
3. Upload index.html, the assets folder (including assets/logo.png), and this README.txt to the repository root.
4. Commit the changes to the main branch.
5. GitHub Pages should publish at https://skidrush27.github.io/; allow a few minutes for the update.

Notes
- Game icons and screenshots are loaded from Google Play-hosted image URLs; an internet connection is needed to display them.
- Please verify the privacy policy against the actual SDKs and data practices in each app before using it as a compliance document.
- privacy.html: standalone privacy policy page suitable for linking from store listings after you verify it matches each app's actual data practices.
